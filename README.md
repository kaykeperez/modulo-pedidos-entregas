# Módulo de Pedidos e Entregas

**Autor:** Carla Cristina

## Objetivo

Este repositório apresenta a estrutura analítica do projeto (EAP) do Módulo de Pedidos e Entregas de um aplicativo de delivery. O objetivo é organizar as principais entregas do projeto em níveis hierárquicos, facilitando o planejamento e o acompanhamento do desenvolvimento.

## Arquivos

- `README.md`: apresentação e objetivo do repositório.
- `EAP.md`: estrutura analítica do projeto em três níveis.

## Projeto

O módulo contempla requisitos, projeto, construção e entrega das funcionalidades relacionadas a pedidos e entregas.
